Measuring on an interactive plot

HTML provides the worksheet, controls and inspector. A plotting library draws traces and maps gestures to coordinates. To measure a value, return to the original sample. The nearest point on the screen can have a different timestamp from the nearest sample in the log.

Inspect a braking event

Select A or B and click anywhere in the plot to place the cursor. Drag to zoom. Use the keyboard to move either time one sample at a time. The difference is always B − A.

Choosing a plotting tool

Plotly.py + Plotly.js

Python figure definitions and a browser demo. Plotly supports traces, scatter plots, histograms, maps and FFT displays. Its browser interactions include hover, zoom, pan, box and lasso selection. A click gives the axis coordinate. The viewer supplies persistent cursors, differences and the lookup from a displayed point to a source row.

Bokeh

A Python option for linked plots. Tools include pan, zoom, crosshair, tap, box and lasso. Two plots can share an axis or a selection. For example, highlight the time samples selected in a scatter plot. A shared data source must represent the same original rows. Indices from independently reduced series can refer to different samples. Browser controls work in standalone HTML. Python callbacks need a running server.

uPlot

A candidate for multiple time-series traces. uPlot draws on Canvas 2D and supports zoom and synchronised cursors. Python can supply its data. Panning and richer touch gestures require integration. A representative multichannel worksheet is the appropriate workload for a comparison with Plotly.

PyQtGraph + PySide6

A native desktop option. The ViewBox supports pan, zoom, linked axes and coordinate conversion. Curves support clipping and downsampling. Movable lines and regions suit cursor-based measurements. This option uses a Qt frontend. Qt can also host HTML through QWebEngineView, which is optional for a local web application.

Datashader

An option for very dense scatter plots. Datashader aggregates density per pixel. Each coloured cell represents a group of samples. Inspect its count and query the underlying data to recover individual values. A separate layer handles interaction.

From gesture to data

Traces. Hover gives a quick reading. Click to pin a time. To recover an original sample, look up its timestamp, value and stable identifier in the source. The index of a reduced point is local to that trace. For asynchronous channels, show the offset from the cursor. In a gap, report “No sample” beyond the stated tolerance.

Scatter plots. Retain the lap, channel and sample identity when picking a point. A lasso on an overview selects displayed points. To compute statistics for all samples inside the selection, apply the polygon to the original data. Histograms and FFTs. Identify the bin range or the frequency and analysis window, respectively.

Controls. Keep inspection, pan and zoom distinct. Preserve zoom and A/B cursors through style changes. Link laps by distance or elapsed time. Provide explicit zoom and reset controls for input devices without a scroll wheel.

Local viewer verification

In a test using a synthetic 5M-row, 100 Hz Parquet file, the overview drew 1,674 points. Dragging to zoom read 149,614 rows from three Parquet groups and kept 1,674 points on screen. The test verified windowed reads. The main viewer did not persist an original-sample selection for imported logs in that test.

In a separate instance using Plotly.js 4.1.1, an experimental click handler requested the ±11 ms window around the pointer time from the existing backend. With this known 100 Hz signal, it selected the nearest original timestamp. Clicking at 6,318.622 s returned 6,318.620 s and 101.87 km/h. The nearest timestamp on the reduced trace was 6,309.840 s.

Nine overview clicks were tested in local Chrome 157 at 1440 × 900. All values matched the source. Each click read one row group. Median time from handler to result was 11.5 ms, including local HTTP and lookup. Drawing and physical mouse latency were outside the measurement. Irregular timestamps require a lookup that accounts for their spacing.
