The public comparison identifies worksheet families. The installed help, release notes and Feature Guide identify additional plot modes. The following 18 examples each have a separate worksheet and HTML element.

For suspension, track maps, histograms and mixture maps, see Components in the installed help. Density, point size and frequency response are also documented in the release notes.

Scope

These examples cover the worksheet families and plot modes listed above. The 2D/3D Math table definition views belong to the calibration editor. Workspace editing, multi-monitor configuration, custom formulae, Excel integration, synchronised video, live telemetry, Picture/WebView components and licensed .ld import are outside the prototype. Specialist worksheets use the simulated session. Imported logs support numeric time histories and configurable XY scatter. The supplied file determines which channels, units and coordinates are available.
